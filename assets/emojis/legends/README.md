# Emojis de leyendas

Coloca aquí una imagen por leyenda antes de ejecutar `npm run emojis:upload`.

Requisitos de Discord:

- 128 × 128 px recomendado.
- Máximo 256 KiB por archivo.
- PNG o WebP con fondo transparente recomendado. También acepta JPEG, GIF y AVIF.
- El nombre del archivo debe ser el nombre de la leyenda: `hattori.png`, `queen_nai.png`, `sir_roland.png`, etc.

El script convierte esos nombres a `legend_hattori`, `legend_queen_nai`, etc. Si un emoji ya existe, lo conserva y continúa.

Usa imágenes cuya licencia te permita subirlas. La Brawlhalla API v1.0 entrega datos de leyendas, pero no entrega sus iconos.
